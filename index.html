About

I'm a software engineer with 8+ years of programming behind me, finishing an MSc in Cyber Security at UEA (Distinction predicted, September 2026). I'm targeting graduate software engineering roles in London. Long term I want to specialise into application and product security engineering, but I want two or three years of proper SWE experience first.

The MSc dissertation is the clearest example of the kind of thing I like building. It's an end-to-end post-quantum authentication pipeline for connected vehicles, in Python and Docker, with ML-DSA (NIST FIPS 204) benchmarked against a classical ECDSA P-256 baseline across 6,000 measured iterations per scheme. Every architectural decision traced back to a STRIDE threat model, and it turned out the binding constraint on post-quantum migration isn't compute, it's signature size. The wire packet is 17.6x larger while verification is only 1.3x slower.

Before the MSc, my BSc dissertation trained a CNN with transfer learning to read handwritten Odia script and hit 84% test accuracy on what's a genuinely low-resource language. Outside coursework I built a CVE triage tool at CyberHack 2026 that filters the daily NVD feed against a defined asset list and enriches results with EPSS exploitation-probability scores and CISA known-exploited flags. And as a taught-module project I OWASP-hardened a full-stack Node.js/PostgreSQL web app: parameterised queries, input sanitisation, CSRF tokens, secure session handling, and least-privilege database access, from the ground up.

UK national, eligible for SC clearance.
